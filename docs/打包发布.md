# 打包与发布

这个项目面向普通用户发布时，目标只有一个：**用户不需要安装 Node.js，也不需要安装 Cocos Creator，拿到文件后解压即用，或者双击打开就能玩。**

为此仓库同时提供了两条发布链路：

1. 桌面安装包：macOS 的 `.dmg`/`.zip`，Windows 的安装版和便携版 `.exe`。
2. 离线单文件 HTML：一个 `.html` 文件，双击用浏览器打开即可。

## 普通用户拿到什么

| 平台 | 产物 | 用户操作 |
| --- | --- | --- |
| macOS | `CodeDungeon-*-mac-*.dmg` | 打开 dmg，把「地牢围攻」拖进 Applications |
| macOS | `CodeDungeon-*-mac-*.zip` | 解压后双击 App |
| Windows | `CodeDungeon-Setup-*-x64.exe` | 双击安装，桌面会出现快捷方式 |
| Windows | `CodeDungeon-Portable-*-x64.exe` | 双击直接运行，无需安装 |
| 全平台 | `CodeDungeon-*-single.html` | 双击用浏览器打开 |

这些产物都不要求用户预装开发工具。

## 维护者本地构建

先确保本机有 Node.js 24 LTS（最低 22.13），然后安装依赖：

```bash
npm install
```

生成网页静态产物和单文件 HTML：

```bash
npm run build
npm run build:single
```

生成本机平台的桌面安装包：

```bash
npm run dist:mac
# 或
npm run dist:win
```

生成的安装包和单文件都在 `release/` 目录。

## GitHub Actions 自动发布

仓库已经配置了 `.github/workflows/release.yml`。只需要：

1. 把代码推送到 GitHub。
2. 打一个以 `v` 开头的 tag，例如：

   ```bash
   git tag v3.8.6
   git push origin v3.8.6
   ```

3. GitHub Actions 会自动在 macOS 和 Windows 两台机器上分别构建：
   - macOS：dmg、zip
   - Windows：安装版 exe、便携版 exe
   - 单文件 HTML
4. 构建完成后，GitHub Release 页面会出现可下载附件。

也可以打开仓库的 Actions 页面，手动触发「构建发布包」工作流。

## macOS 签名与 Gatekeeper

当前配置生成的是**未签名/未公证**的 macOS 应用，因为开源项目通常不会把 Apple 开发者证书放进 CI。

第一次打开时，macOS 可能会提示“无法验证开发者”。用户可以：

- 右键点击 App → 打开；或
- 在「系统设置 → 隐私与安全性」里选择“仍要打开”。

如果要做到双击完全无提示，需要：

- 申请 Apple Developer 证书；
- 在 CI 中配置 `CSC_LINK`、`CSC_KEY_PASSWORD`、`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`；
- 开启 notarization。

## Windows 签名与 SmartScreen

未签名的 Windows 安装包在第一次下载时可能触发 SmartScreen 提示，这是正常现象。要消除提示需要购买代码签名证书，并在 CI 中配置 `CSC_LINK` 和 `CSC_KEY_PASSWORD`。

## 如果你只想要网页版

如果暂时不想做桌面安装包，也可以直接发布单文件 HTML，或者把 `dist/` 目录部署到 GitHub Pages / Cloudflare Pages。这样用户打开一个网址就能玩，完全不用下载安装。
