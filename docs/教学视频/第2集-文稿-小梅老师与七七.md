## 本集与第 1 集的差异

- 第 1 集做完了游戏介绍和自我介绍，**本集直接进教学**，不再重复介绍。
- 片头只报集数，进场问候换成「这一集我们一起学第二章」。
- 教学主体从「顺序执行」升级到「for 循环」，覆盖第 11~22 关。
- 结尾照旧：通关小结 → 布置作业 → 退场告别 → 片尾卡，并预告第 3 集的 if 判断。
